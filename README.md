# Let's Snack - Página de Administração
![Imagem do Projeto](https://github.com/user-attachments/assets/a4eec270-fbb3-4c16-b204-4ec2ccb3787e)

## Sobre o Projeto
A Página-ADM do projeto Let's Snack é um painel administrativo desenvolvido para gerenciar os dados do sistema. Ele permite a realização de operações CRUD (Criar, Ler, Atualizar e Deletar) sobre os itens das tabelas cadastradas no banco de dados, possibilitando que os administradores tenham controle total sobre os dados e operações do aplicativo.

O projeto serve para que os administradores do aplicativo possam ter acesso aos dados de 5 tabelas no banco de dados, permitindo controlar e monitorar todas as atividades e operações do Let's Snack.

## Tecnologias Utilizadas
O projeto foi desenvolvido utilizando as seguintes tecnologias:
- **Linguagens de Programação e Frontend:**
  - Java
  - HTML
  - CSS
  - JavaScript
- **Banco de Dados:**
  - MongoDB
  - SQL

## Instalação e Execução

### Para Desenvolvedores:
1. Instale uma IDE compatível (como IntelliJ IDEA ou VS Code).
2. Clone este repositório.
3. Certifique-se de ter o MongoDB e o banco de dados SQL configurados corretamente.
4. Abra o projeto na IDE e configure as dependências necessárias.
5. Inicie o servidor e acesse a página de administração com login e senha cadastrados.

### Para Usuários:
Se você for apenas um usuário comum, basta acessar o link da página principal do Let's Snack sem necessidade de login administrativo.

## Uso
O aplicativo será usado para realizar os seguintes procedimentos com os dados:
- Visualização
- Inserção
- Alteração
- Remoção
